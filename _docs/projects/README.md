# Project Landscape

Surfbuddy is a wind forecast site for windsurfers, split across three independent repositories.

## Repositories

- `surfbuddy-server` — server installation and setup.
- `surfbuddy-v3` — API and scripts for generating forecasts.
- `surfbuddy-vue` — frontend.
